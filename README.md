## [!] El Problema y la Solución

Cualquiera que haya emigrado sabe el dolor de cabeza que representa entender la burocracia consular y de extranjería: requisitos cambiantes, información dispersa y procesos eternos. Este proyecto nace para resolver esa barrera, un asistente disponible 24/7 que te servira de guia para consultas sobre pasaportes, residencia, homologaciones y trámites en España de manera clara y rápida.

# { } Arquitectura y Tecnologías

La web combina una interfaz minimalista y responsive . Esta Construido con **HTML5**, **Tailwind CSS** y **JavaScript (ES6+)** .
* **Integración de IA (Chatbase):** Configuración, entrenamiento de base de conocimiento y consumo del agente virtual alimentado por el motor de **Chatbase**, integrado en la interfaz web.
