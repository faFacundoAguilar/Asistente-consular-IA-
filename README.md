## [!] El Problema y la Solución

Cualquiera que haya emigrado sabe el dolor de cabeza que representa entender la burocracia consular y de extranjería: requisitos cambiantes, información dispersa y procesos eternos. Este proyecto nace para resolver esa barrera, un asistente disponible 24/7 que te servira de guia para consultas sobre residencia, pasaportes, homologaciones y trámites en España de manera clara y rápida.

# { } Arquitectura y Tecnologías

>  **A diferencia de una IA general, este asistente no inventa ni asume respuestas.**
> **Está entrenado y estructurado exclusivamente sobre la normativa, requisitos y canales oficiales de los consulados argentinos y la legislación de extranjería** **en España. Es una herramienta de **orientación precisa y especializada**, diseñada para darte información verificada, estructurada y al grano, ahorrándote horas** **de búsqueda en foros y páginas oficiales desactualizadas.**

La web combina una interfaz minimalista y responsive . Esta Construido con **HTML5**, **Tailwind CSS** y **JavaScript (ES6+)** .
* **Integración de IA (Chatbase):** Configuración, entrenamiento de base de conocimiento y consumo del agente virtual alimentado por el motor de **Chatbase**, integrado en la interfaz web.
